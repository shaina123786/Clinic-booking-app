# Clinic Appointment Booking API

A RESTful API built with Node.js, Express, and SQLite for managing clinic time slots and appointment bookings. It prevents double-booking using database constraints.

## Features
- Create, list, and delete time slots
- Book appointments for available slots
- Cancel existing bookings
- Prevention of double-booking
- Automated tests for booking logic

## Tech Stack
- Node.js
- Express.js
- SQLite3
- Jest & Supertest
